09 / Empirical software engineering research

Analyzing the Quality of Agentic Code

A study on code smells and dependency failures · MSR 2026 Mining Challenge

An empirical comparison of AI-agent-authored and human-authored pull requests on GitHub using the AIDev dataset (50 agentic + 50 human Python PRs). Human PR descriptions are ~7.5× longer on average (5,669 vs 755 characters) and carry significantly more dependency-management signals (Mann–Whitney U, p = 0.0002, Cliff's δ = −0.36); agentic PRs mention testing more often. Static analysis with radon and pylint on the changed files found no statistically significant difference in cyclomatic complexity or smell density at this sample size. Co-authored with Iyashi Pal.

12 / Quantum cryptography

BB84 Quantum Key Distribution

Qiskit · with Eve's intercept-resend attack

A runnable simulation of the BB84 protocol: Alice encodes key bits in random Z/X bases, Bob measures, and the sifted key is checked for eavesdropping via the quantum bit-error rate. Without Eve the QBER is 0% and a secure key is produced; with an intercept-resend attacker it jumps to 24.49% (theory: 25%) and the protocol aborts. Runs on AerSimulator or real IBM Quantum hardware with one flag.
